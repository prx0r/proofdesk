THE PROBLEM

Should your agent be able to sign?

0:00 — The Premise

An AI agent receives a plain-language instruction:

"Prepare the Northstar Data Systems vendor agreement for $42,500 and send it to our CFO for signature."

The agent can extract data, generate agreements, merge PDFs, and compress documents. But signing is irreversible — it creates a legal commitment.

ProofDesk inserts a server-side SignatureGate between reversible document work and irreversible signature. The agent can prepare everything. It cannot sign.
