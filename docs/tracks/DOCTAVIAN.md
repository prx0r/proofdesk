## Challenge Description (word-for-word)

Doctavian is an intelligent document operations platform for generating and digitally signing documents — built for structured data with real complexity, not just flat fields swapped into a form letter.

Most document APIs are glorified mail-merge — swap a name, swap a number, ship it. Doctavian's templates are smarter than that. Built on expressions and elements that branch, loop, and calculate on the fly, one template carries the logic to handle whatever data shows up — and shapes the result correctly, every time.

Once a document is right, it doesn't have to stop there. Doctavian carries it forward too — to signed, sealed, and provable, if that's where your solution needs to go.

Your challenge: bring us your messiest, most real-world data problem, and build an AI agent that turns it into a document that gets it right — repeatedly. Take it all the way to signed if your idea calls for it.

Your agent needs to actually call Doctavian's generation API to shape a real document — not just talk about one.
