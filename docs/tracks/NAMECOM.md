## Challenge Description (word-for-word)

Build a product powered by the name.com API. This challenge asks developers to integrate the name.com API into a working product, using it for domain search, availability checks, registration, or DNS management as a core part of the build.

The format is open. Participants can build something new or extend an existing project, as long as the name.com API is functionally central to what they ship. Judges want to see the API doing something the product actually depends on.

---

## Judging Criteria

**API integration depth:** How central is the name.com API to the product. Judges favor integrations that combine multiple endpoints (search plus registration plus DNS, for example) over a single surface-level call.

**Creativity and originality:** Is the use case distinct. Judges favor unexpected applications over incremental tweaks on existing domain search tools.

**Technical execution:** Code quality, architecture decisions, and how well the team handled edge cases.

**Real-world viability:** Could this plausibly become a product or feature people would use. Judges weigh market relevance and clarity of the value proposition.

**Presentation and demo:** Clarity of the final walkthrough. Judges want to see the integration in action, not just slides.
